# アクセスログ調査ツール

Windows 上で、Apache のアクセスログを案件ごとに SQLite へ取り込み、フィルタ・集計・CSV 書き出しをする個人用ツールです。ブラウザは `127.0.0.1` だけに公開します。ログインはありません。

## 起動（Docker）

[Docker Desktop](https://www.docker.com/products/docker-desktop/) を起動したうえで、プロジェクトのルートで:

```powershell
docker compose up --build
```

コンソールに `http://127.0.0.1:8765/` と出たら、その URL をブラウザで開きます。

- ホストへ出す待受はループバックのみ（`127.0.0.1:8765`）
- 案件データは Compose の volume `data` に残ります。`docker compose down` では消えません
- 止めるときは Ctrl+C、または別のターミナルで `docker compose down`
- テンプレートや CSS/JS を直したあとは、同じ `docker compose up --build` が必要です（イメージにソースを焼き込むため）

バックグラウンドで動かす場合:

```powershell
docker compose up --build -d
```

止めるときは `docker compose down`。

## 起動（仮想環境）

Docker を使わない場合:

```powershell
.\scripts\run.ps1
```

ポートを変える場合は `.\scripts\run.ps1 --port 9000` のように指定します。案件データはプロジェクトの `data/` に残ります。

## 使い方

### 案件を作る

1. 案件一覧で名前と `LogFormat` を入れる
2. 必要ならサンプル 1 行で分割結果を確認する
3. 登録する。LogFormat はあとから変えられません

`%r`（Request）がある新規案件では、取り込み時に Request-Method / Request-Path / Request-Query / Request-Protocol も列になります。Path に `?` 以降は含みません。Query に先頭の `?` は含みません。既存案件を直すには、作り直して取り込む必要があります。

### ログを取り込む

作業画面の「取り込み」タブでファイルを選び、「取り込み開始」を押します。

- 複数ファイル可。`.gz` は展開して読みます
- 対象は名前が `access_log` で終わるもの、拡張子なし、または `.gz`
- 案件内で内容がまったく同じ行は登録しません（重複）
- 同じファイル名が既にあるときは確認します。続行する場合は「同じファイル名が既にあっても追加して取り込む」を付けます

取り込んだファイルは一覧の「削除」から消せます。元ファイル名単位で、その行・カスタム値・取り込み履歴がまとめて消えます。取り消しはできません。

### 絞り込む

左の検索条件で列・演算子・値を足し、「条件を適用」します。複数条件は AND です。

文字列の演算子:

- 等しい / 等しくない（完全一致。等しくないは未設定の行も残す）
- 含む / 含まない、始まる / 始まらない
- 複数選択 / 複数選択以外（カンマ区切り。例: `GET,POST`）
- 以上 / 以下（辞書順）

条件に名前を付けて保存し、あとから呼び出せます。解除で全件に戻ります。

大きな案件では、条件を変えた直後と CSV 書き出しに時間がかかることがあります。タブの切り替えは、条件が同じあいだ件数を数え直しません。数百万行の案件は、更新後の最初のオープンで索引を作るため、一度だけ待たされることがあります。

### 一覧・集計・CSV

- 一覧: 一致行を先頭から表示します。「続き」で次のページです
- カスタムフィールド: 案件情報タブで列を足し、一覧のセルや一括設定で値を入れます。一括は一致行全体が対象です（見えている行だけではありません）
- 集計: グループ列や時間バケットを選んで実行します
- CSV: 一覧から一致行、集計タブから集計結果を書き出せます

### 案件を消す

案件一覧のメニューから削除します。その案件の SQLite ファイルごと消えます。
