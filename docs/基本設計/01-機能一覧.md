# 機能一覧

単一業務。面の方式は組み込み（同一プロセスが HTML を返す）。管理画面の利用者は自分。方式設計 [00-全体.md](../方式設計/00-全体.md) に従う。

論理データは [03-データ構造設計.md](03-データ構造設計.md)。メッセージは [05-メッセージ一覧.md](05-メッセージ一覧.md)。

## 機能分類一覧

| 機能分類ID | 機能分類名 | 概要 |
| ---------- | ---------- | ---- |
| LCH | 起動 | プロセスの起動と停止 |
| CSE | 案件 | 案件の一覧・作成・名称変更・削除 |
| WRK | 調査 | 1 案件の取り込み・フィルタ・一覧・分類・集計 |
| EXP | 出力 | CSV ファイルの書き出し |

## 画面一覧

| 機能ID | 機能名 | 機能概要 | エンドポイント |
| ------ | ------ | -------- | -------------- |
| CSE_D01 | 案件一覧画面 | 案件の作成、一覧、名称変更、削除。作業画面へ移る | `GET /` |
| WRK_D01 | 案件作業画面 | 取り込み、フィルタ、名前付きフィルタ、一覧、カスタムフィールド、一括設定、集計、CSV 起動 | `GET /cases/{案件公開識別子}` |

## バッチ・コマンド一覧

| 機能ID | 機能名 | 機能概要 |
| ------ | ------ | -------- |
| LCH_B01 | 起動コマンド | 仮想環境上で Flask を 1 プロセス起動し、ループバックの固定ポートで待つ。使い終わったらプロセスを止める |

## 出力一覧

| 機能ID | 機能名 | 機能概要 |
| ------ | ------ | -------- |
| EXP_F01 | 一致行CSV | いまのフィルタに一致したアクセスログデータを CSV で書き出す。WRK_D01 から呼ぶ |
| EXP_F02 | 集計結果CSV | いまの集計結果を CSV で書き出す。WRK_D01 から呼ぶ |

## 共通処理一覧

| 機能ID | 機能名 | 機能概要 |
| ------ | ------ | -------- |
| CSE_C01 | LogFormat解析 | Apache の LogFormat 文字列からフィールド定義を作り、ログ行を項目に分割する。CSE_D01 と WRK_D01 から呼ぶ |
