# データ構造設計書

[← 機能一覧](01-機能一覧.md)

方式設計 [A04-データ方式.md](../方式設計/A04-データ方式.md) に従い、案件ごとに 1 ファイルへ永続する論理データ。項目名は日本語論理名。物理テーブル・索引は書かない。

## データ一覧

| データ | 概要 |
| ------ | ---- |
| 案件 | 調査の単位。名前と LogFormat |
| ログフィールド定義 | LogFormat から決まる項目 |
| カスタムフィールド定義 | 利用者が足す文字列項目 |
| 取り込みファイル | 取り込んだ元ファイルの情報 |
| アクセスログ行 | ログ 1 行。行 ID と日時 |
| ログフィールド値 | 1 行のログ項目の値 |
| カスタムフィールド値 | 1 行のカスタム項目の値 |
| 名前付きフィルタ | 案件内に保存した条件の組み合わせ |

## 公開識別子

| 識別子 | 露出先 | 形式 | 備考 |
| ------ | ------ | ---- | ---- |
| 案件公開識別子 | URL、SQLite ファイル名 | UUID（v4）。ハイフン付き 36 文字 | 人が読む名前は案件名 |
| 行ID | 画面一覧、一致行 CSV | 案件内の整数連番。1 から付与。振り直さない | 行削除が無いため欠番は出にくい |

名前付きフィルタとカスタムフィールドは、利用者が付けた名前で指す。自動発番の公開 ID は置かない。

## 入出力・保管形式

| 項目 | 入力形式 | 保管形式 | 備考 |
| ---- | -------- | -------- | ---- |
| 日時（Time） | フィルタでは日付と時刻（秒まで）。TZ は選ばない | 表示用にログの文字列。比較・バケット用に絶対時刻。バケットはログの TZ 上 | 対話で決定 |
| 案件名 | 1 行テキスト | 前後空白を除く。空不可。1〜100 文字。文字種制限なし | カスタムフィールド名、名前付きフィルタ名も同じ |
| LogFormat文字列 | 複数行可のテキスト貼り付け | 前後空白を除く。空不可。内容は入力のまま | 解釈は CSE_C01 |
| カスタムフィールド値 | 1 行テキスト。空可 | 空は未設定。前後空白は除かない（想定） | 一括でも空は未設定 |
| 時間バケット | 整数 n と単位（秒／分／時間） | n は 1 以上の整数。単位は秒・分・時間のいずれか | 上限は置かない（想定） |

## 案件 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | 公開識別子。ファイル名と URL に使う |
| 案件名 | 文字列 | 表示名。一意制約なし |
| LogFormat文字列 | 文字列 | 登録時の書式。登録後は変更しない |
| 作成日時 | 日時 | システムが付与 |

## ログフィールド定義 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | 所属案件 |
| 表示順 | 整数 | LogFormat 上の出現順。Request 分解列があるときは Request の直後に挿入し、以降をずらす |
| フィールド識別子 | 文字列 | label または引数名（例: RemoteHost、User-Agent、Request-Path） |
| フィールド型 | 区分 | 文字列／数値／日時 |
| 指定子 | 文字列 | 元のトークン（例: `%h`、`%{User-Agent}i`）。修飾子は識別子を変えない。分解列は `derived:%r` |
| 時間軸 | 真偽 | 日時型かつ時間バケットの軸（`%t` または strftime の Time） |

同一案件でフィールド識別子の重複は不可。

## カスタムフィールド定義 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | 所属案件 |
| カスタムフィールド名 | 文字列 | 案件内で一意。ログのフィールド識別子とも重ねない。型は常に文字列 |
| 表示順 | 整数 | 追加順 |

## 取り込みファイル 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | 所属案件 |
| 元ファイル名 | 文字列 | 利用者が選んだファイルの名前。パスは持たない（想定） |
| 取り込み日時 | 日時 | 確定した時刻 |
| 読んだ行数 | 整数 | |
| 入れた行数 | 整数 | |
| 捨てた行数 | 整数 | 解釈できなかった行 |
| 重複行数 | 整数 | 案件内に同一のログ行内容があり登録しなかった行 |

同じ元ファイル名を再取り込みした場合は別レコード。削除は元ファイル名単位で、同じ名前の履歴と行をまとめて消す。

## アクセスログ行 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | 所属案件 |
| 行ID | 整数 | 案件内連番。公開識別子 |
| 元ファイル名 | 文字列 | 取り込みファイルの元ファイル名 |
| ファイル内行番号 | 整数 | そのファイル内の行位置 |
| ログ行内容 | 文字列 | ファイル上の 1 行。末尾の改行は含めない。案件内で一意。画面・CSV には出さない |
| 日時表示 | 文字列 | ログに書かれた Time の見た目。未設定なら空 |
| 日時絶対 | 日時 | 比較用。未設定なら無し |
| 日時オフセット | 文字列 | ログの TZ オフセット。バケット計算に使う。未設定なら無し |

## ログフィールド値 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | |
| 行ID | 整数 | |
| フィールド識別子 | 文字列 | ログフィールド定義と対応 |
| 未設定 | 真偽 | 真なら値なし（数値の `-`。`%b` の `-` は 0 で未設定ではない） |
| 文字列値 | 文字列 | 型が文字列のとき。`-` はそのまま |
| 数値値 | 整数 | 型が数値のとき |

日時型の値はアクセスログ行の日時項目に持つ（フィールド値とは二重にしない）。

## カスタムフィールド値 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | |
| 行ID | 整数 | |
| カスタムフィールド名 | 文字列 | |
| 未設定 | 真偽 | 真なら値なし（未入力または空に戻した） |
| 文字列値 | 文字列 | 未設定でないとき |

## 名前付きフィルタ 定義

| 項目名 | データ型 | 内容 |
| ------ | -------- | ---- |
| 案件公開識別子 | 文字列（UUID） | |
| フィルタ名 | 文字列 | 案件内で一意 |
| 条件内容 | 文字列 | 列・演算子・値の組み合わせ。形式の物理表現は内部設計 |
