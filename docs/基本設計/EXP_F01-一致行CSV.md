# EXP_F01 一致行CSV 基本設計書

[← 機能一覧](01-機能一覧.md) · [データ](03-データ構造設計.md) · [メッセージ](05-メッセージ一覧.md)

WRK_D01 から呼ぶ。

## 概要

いまのフィルタに一致したアクセスログ行を CSV で書き出す。見えている行ではなく全件。打ち切らない。

行順: 一覧タブで選んでいる並びと同じ（行ID昇順、または Time 昇順で同着は行番号昇順、または Time 降順で同着は行番号降順）。列順は変えない。

### ファイル形式

| 項目名 | 内容 |
| ------ | ---- |
| ファイル形式 | CSV |
| 文字コード | UTF-8（BOM 付き） |
| 改行コード | CRLF（Windows。想定） |
| 区切り文字 | カンマ。値にカンマ・改行・引用符があれば RFC 4180 どおり引用 |
| ヘッダー有無 | あり（1 行目は項目名） |

保存先とファイル名は、書き出しのたびに利用者が選ぶ。

## 入力項目

| 項目名 | 内容 |
| ------ | ---- |
| 案件公開識別子 | 対象案件 |
| 条件内容 | いま適用中のフィルタ。未適用なら全件 |
| 並び | いまの一覧の並び。未指定・Time 無しは行ID順 |
| 保存先 | 利用者が選んだパス |

実行前に I_EXP_INF01（対象件数）。失敗時は途中ファイルを残さず E_EXP_SYS01。成功は S_EXP_OK01。進行は同一応答で流す（方式 A03）。

## 出力項目

| 項目名 | 内容 |
| ------ | ---- |
| 行ID | 整数 |
| 元ファイル名 | |
| ファイル内行番号 | |
| （ログフィールド識別子ごと） | 文字列または数値。未設定は空欄。日時は日時表示 |
| （カスタムフィールド名ごと） | 未設定は空欄 |

列順: 行ID、元ファイル名、ファイル内行番号、ログフィールド定義の表示順、カスタムフィールド定義の表示順。
