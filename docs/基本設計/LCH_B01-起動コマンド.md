# LCH_B01 起動コマンド 基本設計書

[← 機能一覧](01-機能一覧.md)

## 概要

Flask を 1 プロセス起動し、ループバックの固定ポートで HTML を返す。使い終わったらプロセスを止める（方式設計 A08）。起動は Docker Compose を主とし、仮想環境のスクリプトも残す。

## 入力項目

### 引数

| 項目名 | パラメータ名 | 型 | 必須 | 内容 |
| ------ | ------------ | -- | ---- | ---- |
| ポート | `--port` | 整数 | — | 省略時は 8765 |

### 環境変数

| 項目名 | 変数名 | 内容 |
| ------ | ------ | ---- |
| 待受アドレス | `ACCESS_LOG_BIND` | 省略時は `127.0.0.1`。許可は `127.0.0.1` / `localhost` / `0.0.0.0`。コンテナ内だけ `0.0.0.0` |

## 処理概要

1. Docker なら `docker compose up --build`。仮想環境ならプロジェクトの venv でアプリケーションを起動する
2. ホストへ公開する待受はループバックのみ（`127.0.0.1:8765`）。Compose の ports で固定する。コンテナ内の待受はポート転送のため `0.0.0.0`
3. ポートは固定。省略時 8765
4. 待受に失敗したら E_LCH_SYS01 を標準出力に出して終了する
5. 成功したら標準出力に `http://127.0.0.1:{ポート}/` を出す。ブラウザの自動起動はしない（想定）
6. 停止はプロセスの終了（Ctrl+C 等）。サービス登録はしない

データディレクトリ `data/` が無ければ作成する。Docker ではホストの `data/` をコンテナの `/app/data` に載せる。
