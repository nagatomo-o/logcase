# メッセージ一覧

[← 機能一覧](01-機能一覧.md)

## 採番

`{E|W|I|S}_{機能分類ID}_{チェック}{連番}`

| チェック | 意味 |
| -------- | ---- |
| `REQ` | 必須 |
| `FMT` | 形式・型・文字数 |
| `RNG` | 範囲 |
| `EXS` | 存在 |
| `DUP` | 重複・一意 |
| `CMB` | 組み合わせ |
| `BIZ` | その他業務 |
| `SYS` | システム |
| `INF` | 情報 |
| `OK` | 成功 |
