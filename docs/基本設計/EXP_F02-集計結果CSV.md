# EXP_F02 集計結果CSV 基本設計書

[← 機能一覧](01-機能一覧.md) · [データ](03-データ構造設計.md) · [メッセージ](05-メッセージ一覧.md)

WRK_D01 から呼ぶ。集計結果が画面に無いときは実行しない（想定: ボタン無効）。

## 概要

いま画面にある集計結果を CSV で書き出す。全グループ。打ち切らない。

### ファイル形式

| 項目名 | 内容 |
| ------ | ---- |
| ファイル形式 | CSV |
| 文字コード | UTF-8（BOM 付き） |
| 改行コード | CRLF（Windows。想定） |
| 区切り文字 | カンマ。RFC 4180 |
| ヘッダー有無 | あり |

保存先とファイル名は利用者が選ぶ。実行前 I_EXP_INF01。失敗 E_EXP_SYS01。成功 S_EXP_OK01。

## 入力項目

| 項目名 | 内容 |
| ------ | ---- |
| 案件公開識別子 | |
| 集計結果 | WRK_D01 で実行したグループ行 |
| 保存先 | 利用者が選んだパス |

## 出力項目

| 項目名 | 内容 |
| ------ | ---- |
| （グループにしたフィールド識別子またはカスタムフィールド名） | グループ値。未設定グループは空欄 |
| 時間バケット開始 | 使う場合のみ。ログ TZ 上の開始日時 |
| アクセス数 | 行数。常に出す |
| （選んだ集計値） | 個数・平均・合計 |

列順はグループ列、時間バケット開始（使う場合）、アクセス数、指定した集計値の順。
