# 権限設計

[← 機能一覧](01-機能一覧.md)

ログインは置かない。権限は「利用者（自分一人）」のみ。

## 権限一覧

| 権限名 | 概要 |
| ------ | ---- |
| 利用者 | この PC でプロセスを起動した本人。全機能を使える |

## 権限マトリクス

| 機能ID | 機能名 | 利用者 |
| ------ | ------ | ------ |
| LCH_B01 | 起動コマンド | ○ |
| CSE_D01 | 案件一覧画面 | ○ |
| CSE_C01 | LogFormat解析 | ○ |
| WRK_D01 | 案件作業画面 | ○ |
| EXP_F01 | 一致行CSV | ○ |
| EXP_F02 | 集計結果CSV | ○ |
