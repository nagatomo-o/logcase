# 名前付き集計

日付: 2026-10-27  
承認済み。フィルタとは別に、集計の組み合わせだけを案件内で名前保存する。

## 残す内容

`groups` / `use_bucket` / `n` / `unit` / `metric_id` / `metric_fn`。フィルタは含めない。

## データ

案件 DB に `named_aggregates (name PRIMARY KEY, spec TEXT)`。既存案件はオープン時に無ければ作る。名前規則はフィルタと同じ（1〜100 文字）。同名は上書き確認。フィルタと同名でもよい。

## 画面と操作

集計タブで保存・呼び出し・削除。呼び出しはフォームを戻し、いまのフィルタのまま集計を実行して集計タブに留まる。取り込み中は他操作と同じく拒否。
