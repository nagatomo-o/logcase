# 文字列の等しい／等しくない

日付: 2026-10-24  
対象: 文字列フィルタに、完全一致と比較の否定を足す。

承認済み。案件データや保存済み条件の移行はしない。

## 1. 目的

文字列列で「この値と完全に同じ」「この値ではない」を、複数選択を使わずに指定できるようにする。

## 2. 演算子

| 項目 | 等しい | 等しくない |
| ---- | ------ | ---------- |
| 画面ラベル | 等しい | 等しくない |
| 内部値 | `eq` | `ne` |
| 対象型 | 文字列のみ（ログ列・カスタム列） | 同左 |
| 演算子の並び | 文字列演算子の先頭 | 等しいの直後 |

数値・日時の既存 `eq` / `ne` は変えない。内部値は同じでも、型で分岐する（現状どおり）。

文字列演算子の並び（変更後）:

等しい、等しくない、含む、含まない、始まる、始まらない、複数選択、複数選択以外、以上、以下

## 3. 入力と保存

値欄は 1 つのテキスト。カンマは区切りにせず、値そのものとして扱う（含むと同じ）。前後空白は trim しない。

適用時の `value` は文字列のままセッションへ保存する。`in` / `not_in` のような `split(",")` はしない。

既存の名前付きフィルタは触らない。`eq` / `ne` を含む文字列条件は、保存すればその案件内で呼び出せる。

## 4. 一致規則

条件同士は AND のまま。大文字小文字は区別する（他の文字列演算子と同じ）。

**等しい（`eq`）**

- その列の値が、入力と完全一致する行だけ残す
- 未設定は残さない

実装: 既存の EXISTS に `col_s = ?`

**等しくない（`ne`）**

- その列の値が入力と完全一致しない行を残す
- 未設定も残す（複数選択以外と同じ補集合）

実装: 等しいの EXISTS を `NOT` する（`NOT EXISTS (... col_s = ?)`）

空入力（値欄が空文字）:

- `eq` は値が空文字の行だけ（未設定は含まない）
- `ne` は値が空文字でない行と未設定（`eq` の補集合）

## 5. 画面

値入力 UI は変えない。条件サマリと一覧タブの適用中チップは、含むと同じく値をそのまま出す（件数表示にはしない）。

新しいメッセージコードは足さない。不正な演算子は既存どおり無視する。

## 6. テスト

- `Request-Method` が `GET` の `eq` で GET だけ残る。`POST` や未設定は残らない
- 同じ列の `ne` で GET 以外が残る。未設定のカスタム文字列も残る
- 値にカンマを含む `eq` は分割せず、その文字列全体と一致する
- 空入力の `eq` は空文字の行だけ。空入力の `ne` はその補集合
- 文字列列の演算子一覧の先頭に `eq` / `ne` が出る。数値・日時の一覧は変わらない
- 既存の含む / 複数選択 / 複数選択以外 / AND は回帰しない

## 7. 文書

要件定義 R02（F-003 文字列演算子）と基本設計 WRK_D01（文字列演算子の列挙）に「等しい、等しくない」を先頭へ追記する。WRK_D01 の条件行説明とフィルタ適用時の説明に、等しくないは未設定を残す旨を足す。メッセージ一覧は変更しない。
