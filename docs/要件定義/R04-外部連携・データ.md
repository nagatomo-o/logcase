# R04 外部連携・データ

[← 全体](00-全体.md)

## 1. 本章の位置づけ

本システムが接続する外部システムは無い。手元へコピーしたファイルと、画面から入れる文字列が入力。保管と保持は本章。手動の入手は [R06](R06-業務運用要件.md)。

## 2. 本文

### 2.1 外部連携一覧

該当なし。対象 Web サーバへは接続しない。ログファイルと `LogFormat` 文字列は利用者が渡す。

### 2.2 データ要件

| データ / マスタ | 概要 | 生成元 | 保管 | 保持期間 | 備考 |
| --------------- | ---- | ------ | ---- | -------- | ---- |
| 案件 | 名前と `LogFormat`、フィールド定義 | 利用者が登録 | 手元 PC 内に永続 | 利用者が案件を消すまで | 期間による自動削除なし（対話） |
| 取り込みファイル情報 | ファイル名、行数、取り込み日時 | 取り込み時 | 同上 | 同上 | 作業画面から元ファイル名単位で削除できる |
| アクセスログデータ | 分割済み 1 行。行 ID、元ファイル、行番号、各フィールド、ログ行内容 | ログファイル | 同上 | 同上 | 1 日およそ 1 万件（対話）。案件内でログ行内容は一意。同一内容は再登録しない |
| カスタムフィールド定義と値 | 文字列。未設定可 | 利用者が追加・編集・一括 | 同上 | 同上。列削除で値も消える | サーバには無い。消失時は失ってよい（対話） |
| 名前付きフィルタ | 条件の組み合わせと名前 | 利用者が保存 | 同上 | 同上 | 消失時は失ってよい（対話） |

保管場所の製品やファイル形式は方式設計で決める。要件は「手元 PC に永続し、案件単位で分かれる」こと。

取り込んだログは、案件削除または取り込みファイル削除で消す。元のログファイル（サーバ上・手元コピー）の保管は本システムの対象外。
