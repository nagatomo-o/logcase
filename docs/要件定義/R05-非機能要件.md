# R05 非機能要件

[← 全体](00-全体.md)

## 1. 本章の位置づけ

性能・機密・実行環境。バックアップは機能対象外のため [R07](R07-保守運用要件.md)。対象 OS は方式設計で Windows のみ（O-001 Closed）。

## 2. 本文

| 区分      | 要件                                                   | 指標 / 目標                                           | 測定方法      | 出典          |
| ------- | ---------------------------------------------------- | ------------------------------------------------- | --------- | ----------- |
| データ量    | 案件の稼働期間によりばらつく。目安 1 日 1 万件。年単位で数百万件                  | 一覧・集計・CSV で件数打ち切りしない                              | 大規模案件での操作 | 対話          |
| 性能      | 落ちないこと。進行状況が分かること                                    | 数百万件でフィルタ／集計／CSV してもプロセスが落ちない。待ちは分単位まで許容。秒数上限なし   | AC-010    | 対話          |
| 一覧      | 全件を一度にメモリへ載せない                                       | スクロールで続きを出す                                       | AC-008    | 対話          |
| 可用性     | 一人が起動しているあいだ使えればよい                                   | 常時稼働・冗長化は求めない                                     | 起動できること   | 対話（一人・都度利用） |
| 同時利用    | 複数人・複数端末の同時利用はしない                                    | 対象外                                               | —         | 設計メモ／対話     |
| セキュリティ  | 自分の PC の外に出さない前提。外へ公開しない。ログインは置かない。画面も CSV もマスキングしない | 認証なし。公開サーバに載せない                                   | 起動方法の確認   | 対話          |
| 法令・規制   | 個別の法令要件は置かない                                         | —                                                 | —         | 元資料になし      |
| 実行環境    | 手元 PC のブラウザで操作する                                     | 対象 OS は Windows のみ（方式設計で O-001 を閉じた）。ブラウザの製品指定はしない | —         | 対話／方式設計     |
| 機密の持ち出し | CSV 保存先は利用者が選ぶ                                       | 選んだ場所以降の管理は手動（R06）                                | —         | 対話          |
