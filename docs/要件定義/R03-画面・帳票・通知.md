# R03 画面・帳票・通知

[← 全体](00-全体.md)

## 1. 本章の位置づけ

利用者が見る画面と、出す CSV。配置・見た目は実装時に決め、出来上がったあとで直してよい（対話）。ワイヤーなし。

## 2. 本文

### 2.1 画面

| 画面名 | 目的 | 主要表示項目 | ワイヤー | 関連機能 |
| ------ | ---- | ------------ | -------- | -------- |
| 案件一覧 | 案件を選び、作る、消す | 案件名、`LogFormat` の先頭、ファイル数、行数、最終取り込み日時 | なし | F-001、F-010 |
| 案件の作業画面 | 1 案件の取り込みから調査まで | 案件情報、取り込み、フィルタ、一覧、一括入力、集計、CSV | なし | F-001〜F-009 |

起動すると案件一覧を開く。ログイン画面は無い。

**操作挙動（案件一覧）**

| 操作 | 条件 | 結果 / 遷移 | エラー時 |
| ---- | ---- | ----------- | -------- |
| 起動 | プロセスが起動している | 案件一覧 | 起動できないときは理由を出す。途中データは残さない |
| 案件を作る | 名前と `LogFormat` を入力 | 案件が追加される | 解釈不能・識別子重複は登録せず理由を出す |
| 行をクリック | 案件がある | その案件の作業画面 | |
| 案件名を変更 | 既存案件 | 一覧の表示名が変わる。`LogFormat` は変わらない | |
| 削除 | 確認する | 案件ごと破棄。一覧から消える | キャンセルなら何もしない |

**操作挙動（案件の作業画面）**

| 操作 | 条件 | 結果 / 遷移 | エラー時 |
| ---- | ---- | ----------- | -------- |
| ファイルを選んで取り込む | `access_log` または `.gz` | 進行状況のあと、新規行だけが追加される。結果に読んだ／入れた／捨てた／重複件数 | 同じファイル名は確認。内容が同じ行は入れない。途中失敗はそのファイル分を確定しない |
| フィルタを足して適用 | 列・演算子・値 | 一致件数と一覧が絞り込まれる | 数値・日時にできない値は実行しない |
| フィルタ解除 | 適用中 | 全件に戻る | |
| 名前を付けて保存 | 条件がある | 案件内の名前付きフィルタになる | 同名は上書き確認（想定） |
| 名前付きフィルタを呼び出す | 保存済みがある | 条件が復元され適用される | |
| 一覧を下へスクロール | 続きがある | 続きの行を出す | 落ちないこと |
| カスタムフィールドのセルを編集 | 1 行 | その行だけ更新。空は未設定 | ログ列は編集できない |
| カスタムフィールドを追加／削除 | 名前が重複しない | 列が増減する | 削除は確認後。取り消せない |
| 一括入力 | フィールドと値（空可） | 確認に対象件数。実行で一致行すべて更新 | キャンセルなら変更なし |
| 集計を実行 | グループ／バケット／集計値 | 結果表 | 日時型 `Time` が無い案件では時間バケット不可 |
| 一致行 CSV | 保存先を選ぶ | ファイルができる | 失敗時は途中ファイルなし。理由を出す |
| 集計 CSV | 集計結果がある。保存先を選ぶ | ファイルができる | 同上 |

作業画面の要素（並びは実装に任せる）: 案件情報（名前、`LogFormat`、列の識別子と型、カスタムフィールド追加削除）、取り込み（ファイル選択、進行、取り込み済みファイル一覧）、フィルタ（条件、適用解除、一致件数、名前付き保存呼び出し）、一覧、一括入力、集計、CSV 2 種。

### 2.2 帳票

| 帳票名 | 用途 | 出力タイミング | レイアウト要件 | 関連機能 |
| ------ | ---- | -------------- | -------------- | -------- |
| 一致行 CSV | フィルタ後のアクセスログデータを表計算等で使う | 利用者が書き出すとき | UTF-8 BOM。列は行 ID、元ファイル名、ファイル内行番号、ログフィールド、カスタムフィールド。全件 | F-009 |
| 集計結果 CSV | 集計表を持ち出す | 利用者が書き出すとき | UTF-8 BOM。列はグループ項目、時間バケット開始（使う場合）、選んだ集計値。全件 | F-009 |

保存先とファイル名は、書き出しのたびに利用者が選ぶ。マスキングしない。選んだ場所への書き出しの管理は [R06](R06-業務運用要件.md)。

### 2.3 通知

該当なし。メール・SMS・プッシュ等の通知は使わない。進行状況とエラーは画面に出す。
