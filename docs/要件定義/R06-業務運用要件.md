# R06 業務運用要件

[← 全体](00-全体.md)

## 1. 本章の位置づけ

システム化せず人が行う作業。フロー全体は [R01](R01-業務フロー.md)。

## 2. 本文

| ID     | 業務              | 頻度                                 | 担当  | 手順概要                                                              | システムとの関係                  |
| ------ | --------------- | ---------------------------------- | --- | ----------------------------------------------------------------- | ------------------------- |
| OP-001 | `LogFormat` の入手 | 案件の開始時                             | 利用者 | 対象サーバの Apache 設定を見て文字列をコピーする                                      | F-001 の入力                 |
| OP-002 | ログファイルの入手       | ログが手元に必要なとき、または調査案件が来たとき。定期バッチではない | 利用者 | サーバに入り、`access_log` または `.gz` を手元へコピーする。手段（SCP、共有フォルダ、USB 等）は問わない | F-002 の入力。本システムはサーバに接続しない |
| OP-003 | 分類の判断           | 調査中                                | 利用者 | 機能名・業務分類などを決める。対応ルールはシステムに持たせない                                   | F-005 / F-007             |
| OP-004 | CSV 保存先の管理      | 書き出しのたび                            | 利用者 | フォルダとファイル名を選ぶ。マスキングしないため、その後の共有・保管は利用者が決める                        | F-009                     |
| OP-005 | データ消失時の取り直し     | 消失したとき                             | 利用者 | サーバ上のログから再コピーして取り込み直す。カスタムフィールドと名前付きフィルタは失う。必要なら分類し直す             | F-002、R07                 |
| OP-006 | 不要案件の破棄         | 不要になったとき                           | 利用者 | 案件削除を実行する。期間満了の自動削除はしない                                           | F-010                     |

マスタの年次手動更新のような定期メンテは無い。
